NAME

lzrscu - display information about Sebastian Lăzărescu

SYNOPSIS

lzrscu [-l] [-s section]

DESCRIPTION

The lzrscu utility displays information about an automatic control & applied informatics student based in [REDACTED]. Currently finishing a B.Eng. at TUIASI and looking for embedded / software engineering roles.

The options are as follows:

-l
List the available sections.
-s section
Only display the specified section. The currently available sections are:
education
Degree and coursework.
projects
Recent projects.
skills
Languages, embedded work, tools.
contact
How to reach me.

With no options, all sections are displayed.

EDUCATION

  • B.Eng. in Automatic Control and Applied Informatics - AC TUIASI (Oct. 2022 - July 2026)
  • Relevant Coursework: Microcontrollers (Architectures & Programming), Real-Time Operating Systems, Digital Signal Processors (dsPIC), Computer Architecture, Data Structures & Algorithms, System Identification, Automatic Control Engineering, Robotics, Mobile Robot Path Planning, Computer Vision, Data Acquisition & Process Interfaces, Neural Networks & Fuzzy Logic

PROJECTS

  • Collaborative UAV-UGV Search-and-Rescue Simulation - bachelor thesis. A drone runs a lawnmower coverage path with a thermal camera to detect victims and georeference them; a ground rover is then dispatched to each location. Built with ROS 2, PX4 SITL, Gazebo, and Nav2.
  • CAN-bus Log Analysis Tool - internship at Continental. A Python tool for decoding and inspecting CAN traces (cantools, pandas) with a Flask web interface.
  • FreeRTOS Embedded Projects - real-time firmware on dsPIC33 (UART, ADC, LCD) using FreeRTOS tasks and queues.

SKILLS

  • Languages: C, C++, Python, HTML/CSS
  • Embedded: FreeRTOS, dsPIC, UART / ADC / I2C, CAN bus
  • Robotics & Tools: ROS 2, Gazebo, PX4, Git, MATLAB/Simulink
  • Systems: Linux & UNIX

EXAMPLES

List the available sections:

$ lzrscu -l

Show recent projects:

$ lzrscu -s projects

Show how to reach me:

$ lzrscu -s contact
